- 配置允许结构和 Secret Ref 标签约束已在服务器实施；浏览器按钮禁用不是唯一防线。
- 历史摘要/原因使用显式隐藏提示；读取不改原记录。未知动作保留位置，不伪造成功动作。
- 迁移模式两页完成创建、编辑、刷新、停用和审计展示；失败不伪造零引用或保留旧审计。

- 复用身份请求、Session/CSRF、持久限流、Workspace 权限和事务边界，没有第二套认证实现。

- 本轮未编辑 `.env`、读取密钥、调用模型/HTTP/MCP、连接生产业务库或改动 Zeabur。
- 隔离浏览器使用随机 schema 与 loopback；未知 API 明确 501；无外域请求。
  清理通过独立 PG 连接确认，失败不会被 web 清理错误覆盖。

## 对抗发现及处置

| 发现 | 修正与证据 |
|---|---|
| 任意审计 outcome/targetType/targetId 被返回 | Python 6 个参数用例及 PG 先得到错误 200；增加有限状态与同空间目标检查，转为固定 409 |
| Python 把 false/0/[] metadata 当空对象 | 只允许 None 作为缺省；其余非对象拒绝，原数据保持 |
| Python 影响面读取非对象快照抛 AttributeError | 两资源 × 三种坏快照先失败；过滤前校验对象，返回固定 409 |
| TS 显式 null 原因被当成缺省空串 | 新 PG 用例先得到错误 200；区分缺省与显式值，复用类型拒绝 |
| 测试 teardown 在 finally 抛错覆盖原始失败 | lint 发现后改为聚合清理错误；lint 无警告，浏览器退出与 schema 清理通过 |
| 审计合并或过滤可能改变集合 | 同时间 ID 倒序、两组合并后 limit、Provider 最近 200 条窗口、未知事件位置均通过 PG 断言 |
