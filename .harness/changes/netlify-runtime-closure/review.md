## 保留的非阻断边界

- 取消运行保留既有人工任务记录；活动记录可能仍显示待审，但不能恢复已取消运行。
- 通知专页与 Operation 可追踪待核对投递；Observability 总览告警不覆盖所有此类投递。
- 模块存在较密集的 SQL/DTO 代码，后续可按查询责任拆分；本轮未声称数值覆盖率达标。
- 外部效果无法由本地数据库提供 exactly-once；不确定结果必须明确核对，不能自动盲重发。
- AWL 云端事件投递、真实模型/通知、生产切流尚未验收，不以合成测试代替。

## 第一性原理与对抗式结论

目标是让短时无状态函数承载可恢复的业务过程，而非把旧 Worker 换成路由名称。
因此需要持久化 Operation、固定版本、节点检查点、独立副作用证据、租约代次与投递 Outbox。
审查重点覆盖了重复投递、取消竞争、外部完成但收据丢失、终态提交中断、跨 Workspace 引用、
审核修改版本留痕、实际评分解析及错误完成感。两轴通过只允许进入最终门禁，不等于已上线。
