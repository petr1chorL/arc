# 对抗式评审回执

## 已检查

- URL 中 Workspace 不是全局 User 停用的影响范围；两端都检查全部 active 管理员关系。
- 已停用 User 与组织管理员不作为被移除的有效 Workspace 管理员；不能误阻断普通成员治理。
- 成员写入口在目标成员读写前取得 Organization 锁；失败回滚不修改用户或写成功审计。
- 限流计数独立提交，422/401 不会回滚预算；IP 取 Netlify Context，不取用户伪造转发头。
- 正文按实际字节计数，不能以缺少/谎报 Content-Length 绕过；异常 Cookie 不使服务 503。
- 发布检查限定 repository、workflow path、push event、完整 SHA、最新 run 和 verify job。
- 合成 PG 工具使用固定 loopback 测试库、唯一 schema；只删除本次创建的 schema，未读生产凭证。
- 本轮未改 UI，无浏览器视觉验收要求；已有研究目录未加入提交。

## 限制

- 这不是全套 23 组合身份 API 的穷尽差分；新增重放覆盖关键状态码、响应字段与全局停用规则。
- 组织锁针对低频成员治理，不声称解决所有登录/改密/邀请竞争或运行队列并发。
- 持久限流桶长期清理与容量监测仍待生产切流前评估；共享出口用户共用 IP 额度。
- 公开 GitHub API 受可用性/限额影响，失败关闭会延迟新发布；已有线上部署继续保留。
- 构建内门禁不是独立平台权限控制，不能抵御有权修改工作流或部署配置的仓库管理员。
- 未改历史 migration；此门禁不替代数据库前向迁移和回滚演练。
- 当前修复尚未进入 Zeabur 生产 API；不能向用户声称生产身份缺陷已消失。
