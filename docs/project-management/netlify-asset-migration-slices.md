## 运行边界

Agent 测试运行、HTTP Tool 调用、Workflow 启动、Evaluation 执行属于后续运行迁移，
不能在治理切片里静默接入付费模型或外部副作用。
在任何混合 Preview 中，新的数据库身份/资产 ID 不能直接交给旧 Zeabur 运行服务。
未迁移的运行入口必须明确阻断或留在旧版完整链路，不能把代理 200 当成新链路成功。

## 对抗式验收

- 发布后改草稿不改变旧版本；禁用资产不改写历史快照。
- 越权与跨 Workspace 查询/修改不得泄漏资产或 Secret。
- 重复请求、唯一约束冲突、数据库失败不得出现成功响应或半写入。
- Preview 测试工具不带固定公开登录入口；合成身份不进入 Production。
- 资产治理迁移完成不等于执行、数据切换、备份恢复、业务签收完成。
