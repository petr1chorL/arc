# 04D 量规与样本治理设计

状态：用户已明确回复“接受”，确认固定错误响应及独立候选治理区域；进入实施准备。
依据同目录 `2026-09-05-netlify-rubric-sample-contract.md` 的源码与9项本地测试。
不实现生产切流、真实评分或样本来源生成。

## 第一性原理

目标是保存不可变、可追溯的评价依据。必要对象是量规草稿/版本、Provider、反馈候选、
源产出物/运行/人工任务、专家审核资格、Golden Sample和审计。样本的输入和期望输出必须来自
受控来源链，不能用手填字段替换；治理成功不证明评分质量或完整人工审核链已迁移。

## 范围及兼容

- 保留契约九条路由与既有响应字段、排序和权限。评分执行、样本集/回归运行、人工任务决策不在本片。
- Rubric PATCH 保留完整写入；默认值、null Provider、维度ID、权重/阈值保持动态契约。
  发布先更新 active/版本再拍快照，不沿用 Agent 的发布前快照规则。
- 保留空空间首次 GET 播种三条默认量规的既有行为，但对 Workspace 行加事务锁后重查，
  防止并发重复播种。默认内容与历史版本值不改，不静默变成管理员初始化接口。
  这是兼容既有读请求副作用，不推荐为新接口复制此模式。
- Golden Sample 保留全局 candidate_id 与 idempotency_key 唯一约束（模型和已发布baseline均存在），
  不新增schema、不改成空间级键，不返回其他空间样本。碰撞返回固定409。
- 需确认的错误兼容收缩：字段校验固定422且不回显input；损坏历史/来源读取固定409，
  不继续泄漏未处理异常；已有乱码错误改可理解固定中文。不会改写原数据。

## 事务与授权

- 复用身份事务边界；量规写锁当前行，Provider依赖共享锁至提交，候选版本冲突409。
  版本、草稿状态和成功审计同事务；失败不能留下半版本。
- 默认播种只锁当前Workspace；不同空间不共用全局应用锁。普通量规编辑不反向取得Workspace锁。
- 样本确认先验证同空间活跃用户/成员/审核人且专家，不能以builder角色代替专家资格。
  锁顺序为资格记录（按统一顺序）→候选→来源记录；实现前核对现有资格修改写路径以避免反序。
- 同候选确认串行；同键/同候选/同审核人重放返回原样本，不能重写reason或输出；
  同键不同候选/审核人或同候选不同键409。跨候选键竞争由已有唯一约束兜底并回滚，
  重查时仍须重新验证所有权和资格，不捕获所有数据库错误伪装成幂等成功。
- 候选详情严格校验原始/修改版本及diff同空间；确认校验修改版本、运行、HumanTask同空间。
  缺失/跨空间来源拒绝，不能返回空文本作为成功。来源只读，不能调用执行接口补齐。
- 样本、候选状态与 human-task 审计在一个事务内提交，沿用既有审计结构，不替换成普通成功日志。

## 页面与隔离

- 量规复用 Evaluations 页及Provider读取；错误关闭相关保存路径，不将依赖加载失败替换为空数据。
- Reviews 现有加载同时依赖tasks/reviewers/groups/runs，不能在本片用假空数组填充。
  在显式迁移模式呈现独立候选治理区域，只调用候选列表/详情/确认；保留原非迁移页不变。
- 候选区域显示来源版本、原文/修改文和diff、确认理由与状态；服务端资格为最终判定，403明确提示，
  不依据前端角色声称用户已是专家。重复确认复用同一请求幂等键；成功后刷新候选。
- 不增加公共Golden Sample列表API；确认响应可展示本次样本，刷新后的已确认状态来自持久化候选。
  已有来源记录可治理，不声称本片可以生成新运行/新反馈候选。
- 新Functions保持休眠无生产path；隔离服务未知API 501，不将新ID代理到Zeabur。

## 验收

1. 九路由双栈共享请求：完整/缺省/null/别名/数值、固定错误、版本快照、来源和幂等结果。
2. 角色/CSRF/成员失效/专家资格、跨空间候选/来源/Provider、不合法历史且原数据不变。
3. 真PG同步门及阻塞观测：默认播种、量规并发发布、Provider停用、同候选确认、跨候选幂等键冲突。
4. 独立SQL核对版本/样本/状态/审计，注入审计失败和来源缺失，确认无半写入。
5. 浏览器量规完整生命周期；合成完整来源链下专家确认、非专家拒绝、刷新状态不丢失；零模型外呼。
6. 新后端/前端全量、lint/build、身份/04A/04B/04C PG及浏览器回归；双轴对抗审查后才本地验收。

设计确认后才进入实施。生产数据迁移、运行与人工审核完整生成链仍由后续步骤验收，不能减少原目标。
